Token list cleaner

Paste the raw text, optionally add the uncollected tokens, then click Clean. Everything runs in your browser; nothing is uploaded.

Rows with a 4-digit token come first, sorted ascending. Rows with only a 1-3 digit token (shaded) follow, also sorted. Undelivered = every cleaned row whose token is not in your uncollected list. Rows with no AM number or no bracketed token are skipped. A row counts as being in the website's Uncollected Bin if its brackets contain "Uncollected Bin".
